#  avatrade 官网部署手册

1. 使用宝塔轻量云服务器
2. 访问宝塔面板（如访问不到，需要修改服务器安全组，放行宝塔网站端口）
3. 宝塔中一键安装php运行环境（LNMP），php版本需要选择5.6版本
4. 上传项目代码，或者到宝塔文件面板使用终端：`git clone https://github.com/liujie2288/avarade.git`
5. 织梦官网下载最新源码包，将织梦官网源码包中的install文件夹复制到项目代码中(现在项目中已复制了最新的instal文件夹，这一步可省略)
6. 在宝塔中添加站点，配置通过ip访问，指向项目目录（整个跑通后，可设置域名dns解析，以通过域名访问）
7. 宝塔面板中初始化数据库root密码为：liujie，方便在执行织梦cms安装程序时输入密码
8. 通过ip访问该站点，执行织梦cms安装程序
9.  安装页面，填写数据库用户名:root,密码:liujie
10. 安装页面，填写数据库名称：avatrade，管理后台初始账号密码：admin，完成安装
11. 安装完成后，访问ip/houtai1019访问后台，使用admin账号密码登录后台
12. 进入系统管理->数据库备份/还原， 执行数据还原（数据库备份文件在项目中，没有sql文件），还原后，账号/密码变更为：guanliyuan888，下次登录请使用该账号密码
13. 进入更新模块，执行一键更新网站数据，更新页面后，检查静态页面是否都生成成功。
